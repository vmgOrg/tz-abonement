# Заметки Бориса: ПДн и сроки хранения

История выдачи — тоже персональные данные и защищается так же, как ФИО и адрес [SRC-06, п. 2.2].
Через год после возврата издания связь записи о выдаче с читателем уничтожается (обезличивание) [SRC-06, п. 4.3].
Обезличенные сведения можно хранить для статистики без ограничения срока [SRC-06, п. 4.3].
Директор хочет хранить историю выдачи «всю, навсегда» и в будущем рекомендовать книги [SRC-02, вопрос 4].
Отдел комплектования просит бессрочную историю выдач по каждому экземпляру [SRC-04, вопрос 5].
Это расхождение с п. 4.3 SRC-06: нужно уточнить, о какой истории идёт речь — с читателем или без него.
Рекомендации возможны только с отдельного согласия читателя [SRC-06, п. 4.4].
Учётная запись удаляется, если читатель три года не обращался и не имеет задолженности [SRC-06, п. 4.1].
В разработке и тестировании используются только вымышленные данные [SRC-06, п. 6.1].
