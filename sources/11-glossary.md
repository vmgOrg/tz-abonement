| Назначение | единые термины для ТЗ на АИС «Абонемент» и обучения работников |

Термины расположены по алфавиту. Курсивом отмечены термины, которые в ЦБС употребляются, но в документах использоваться не должны.

| Термин | Определение |
|---|---|
| *Абонент* | Разговорное название читателя. В документах не используется, следует писать «читатель». |
| Абонемент | Форма обслуживания, при которой издания выдаются читателю для использования вне библиотеки (положение, п. 1.2). Не путать с названием системы — АИС «Абонемент». |
| АИС «Абонемент» | Создаваемая автоматизированная информационная система учёта читателей и выдачи изданий (приказ от 01.09.2026 № 47-о). |
| АРМ | Автоматизированное рабочее место — компьютер работника с установленным программным обеспечением. |
| Библиотека | Центральная городская библиотека или библиотека-филиал ЦБС. |
| Библиотека-фондодержатель | Библиотека, за которой числится экземпляр (обозначается сиглой). |
| Бронирование | Закрепление издания за читателем на ограниченный срок (сейчас — 3 дня) или постановка читателя в очередь на издание, находящееся на руках. |
| ВСО | Внутрисистемный обмен — временная передача экземпляра из одной библиотеки ЦБС в другую для выдачи читателю. Оформляется актом ВСО, экземпляр продолжает числиться за библиотекой-держателем. |
| Выдача | Передача экземпляра читателю во временное пользование с фиксацией срока возврата. |
| Должник | Читатель, не вернувший издание в установленный срок. |
| Дневник учёта работы | Ежедневная учётная форма библиотеки: посещения, выдача по видам изданий и отраслям знания. |
| Издание | Произведение печати (книга, журнал и т. п.) как библиографическая единица. Одно издание может быть представлено несколькими экземплярами. |
| Инвентарный номер | Уникальный в пределах ЦБС номер экземпляра. |
| Книжный формуляр | Карточка в кармашке экземпляра, в которой отмечаются выдачи. Упраздняется с вводом АИС. |
| Материально ответственное лицо (МОЛ) | Работник, отвечающий за сохранность закреплённого за ним фонда: в филиале — заведующая филиалом, в ЦГБ — заведующий отделом, за которым закреплён фонд. |
| Местонахождение экземпляра | Где экземпляр находится сейчас: на полке библиотеки-фондодержателя, у читателя или в другой библиотеке по ВСО. Может не совпадать с сиглой. |
| Перерегистрация | Ежегодное подтверждение данных читателя (положение, п. 2.5). |
| Продление | Увеличение срока возврата выданного издания (положение, п. 3.4). |
| Сигла | Условное обозначение библиотеки-фондодержателя, за которой числится экземпляр (ЦГБ — «А», филиал № 1 — «Ф1» и т. д.). |
| Срок возврата | Дата, не позднее которой читатель обязан вернуть издание. |
| Фонд | Совокупность экземпляров, числящихся за библиотекой (фонд библиотеки) или за ЦБС в целом. |
| *Формуляр* | Без уточнения в документах не используется: следует писать «формуляр читателя» или «книжный формуляр». |
| Формуляр читателя | Учётный документ читателя: персональные данные и сведения о выдачах. В АИС заменяется учётной записью читателя. |
| ЦБС | Муниципальное бюджетное учреждение культуры «Централизованная библиотечная система г. Энска». |
| ЦГБ | Центральная городская библиотека — головная библиотека ЦБС. |
| Читатель | Физическое лицо, записанное в библиотеку и пользующееся её услугами. |
| Читательский билет | Документ, удостоверяющий право читателя пользоваться библиотекой; содержит номер читателя. |
| Экземпляр | Отдельный физический экземпляр издания с инвентарным номером. |
| 6-НК | Форма федерального статистического наблюдения «Сведения об общедоступной (публичной) библиотеке». |
